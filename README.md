# Loop Delivery

**Loop Delivery** is a 2D top-down pixel-art exploration and route-optimization game set in the town of Oakhaven. As a summer courier caught in a 10-minute repeating day (07:00 to 00:00), you must deliver packages, unlock faster transportation and shortcuts, and uncover the mystery behind **Parcel #0000** before the midnight anomaly resets the town.

Developed for the **Videogame Design and Programming** course at **Politecnico di Milano** (A.Y. 2026/2027).
