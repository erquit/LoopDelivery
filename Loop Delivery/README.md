# Instruction on how to work inside the project

Here are some things to keep note while working on the project:

## _Game Folder

This is the folder where the main game sits, so please update it carefully so that we don't have many conflicts.

## _Sandbox Folder

This is the folder where each one of us gets to have their own playtest environment, where we cannot conflict with each other (considering that you will only work and try stuff inside your own folder)

## Moving a mechanic from sandbox into the game

1. Build and test the mechanic in your sandbox.
2. When it works, move its scripts and prefabs from _Sandbox/You/ into _Game/.
3. Open a pull request, and have someone else look at it.
4. Put the mechanic into the scenes, one person per scene at a time.
